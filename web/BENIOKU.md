# web/ — laboratuvar web panelleri

Harita, grafik, telemetri, senaryo editörü ve formlardan oluşan laboratuvar arayüzü bu dizinde web teknolojisiyle yazılacaktır (iskelet §7; bölüm 08; W5). Sim sunucusuyla A3 sözleşmesi üzerinden konuşur. Node yalnız bu panellerin derlemesinde kullanılır; çalışan simülatörde ya da kartta koşmaz. Bu sürümde dizin boştur; ön yüz paketleri ilgili işte kilit dosyasıyla sabitlenir (09 §2.6).
